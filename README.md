Hermes: Privacy Policy

Hermes is a personal-use application created and used by a single individual. It accesses only the owner’s own Google Calendar and Gmail data, solely to run the owner’s personal assistant. It does not collect data from any other users, does not sell or share data with third parties, and does not use data for advertising. Data is processed locally on the owner’s own machine and is not stored on any external servers. Contact: firefonix1@gmail.com
